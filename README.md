# ps7-teambook

## Project Info
- **Assignment:** PS7
- **Project Name:** TeamBook (Employee Directory)
- **API Used:** DummyJSON (Users & Todos)
- **Live Link:** https://team-book-beta.vercel.app/

## Routes
- `/` : Home page with Hero section
- `/employees` : List of all employees with search and department filter
- `/employees/:id` : Detailed view of a specific employee and their tasks
- `*` : 404 Error page
